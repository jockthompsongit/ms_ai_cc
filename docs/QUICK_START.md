# Quick start

Vanderbilt MS AI Command Center: Cursor + Obsidian vault. No web app.

## Setup

1. Open this folder in Cursor: `C:\Users\jockt\dev\ms_ai`
2. Open Obsidian vault: `C:\Users\jockt\Dropbox\Vandy_MS_AI`
3. Read [AGENTS.md](../AGENTS.md) before ingest or homework help
4. Use [command-center/HOME.md](../command-center/HOME.md) as the weekly dashboard
5. First-time scripts: `python -m venv .venv` then `pip install -r scripts\requirements.txt`

## Day-to-day

- Dump materials → `Dropbox\Vandy_MS_AI\Content\`
- Granola after class → `Content\...\sessions\granola-YYYYMMDD.md`
- `python scripts\convert_content.py --week N`
- Ask Cursor as **Librarian** to ingest; **Tutor** to study; **Homework Coach** for assignments
- US Signal monthly: **US Signal Advisor** + `us-signal/BRIEF_TEMPLATE.md`
